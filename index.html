Start package

The start package comes from the Time Register (button Export Start Package). It holds your projects with numbers and data. Save the file on the phone and choose it here.

Send to the Time Register

One file with all hours and expenses that are not sent yet. Send it to yourself by e-mail, save it in the Phone folder on the computer and press Import from Phone in the Time Register.

Clean up

Items that are already exported can be removed from the phone. Items that are not exported are never removed.
